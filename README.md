## La Palabra, cada día

Abre Biblia Diaria y encuentra las lecturas, el Evangelio y las palabras de los Papas para hoy. Un lugar sencillo para detenerte, reflexionar y llevar la Palabra contigo durante el día.

- **Lee a tu ritmo.** Empieza con las lecturas de hoy o vuelve a otra fecha desde el calendario.
- **Dedica un momento a escuchar.** Escucha las lecturas mientras descansas o comienzas la mañana.
- **Hazla tuya.** Elige español o inglés, ajusta el tamaño de letra y cambia entre modo claro y oscuro.
- **Encuentra una oración.** Entra en *Extras* para rezar Ven, Espíritu Creador, Ángelus, Salve Regina o Acordaos.

## Un espacio para ti

Una lectura al despertar. Una oración en medio del día. Un momento de calma al terminar la jornada. Tú eliges cuándo.

## Empieza hoy

1. [Descarga la app para Android](https://github.com/jahruz67/Bible-Daily/releases).
2. Abre el archivo APK y sigue las indicaciones de tu teléfono para instalarla.
3. Abre **Biblia Diaria**. Las lecturas de hoy te esperan.

Necesitas conexión a Internet para cargar nuevas lecturas. Las voces disponibles para escuchar dependen de tu dispositivo.
